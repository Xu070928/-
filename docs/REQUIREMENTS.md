# 需求基线 · 2026-11-06

最终交付：Windows 11 离线优先软件。先验证算法可行性，再完善实时监控。
用户设备自述R9-8945，GPU/内存/显存未确认。

1. 多人分别跟踪，区分未佩戴和佩戴不规范。
2. 非高空工作服人员忽略；工作服或高处作业无法确认进入人工复核。
3. 挂钩未挂、未连接可靠锚点、挂点低于工作面判违规。
4. 安全绳缠绕但连接不明、遮挡、模糊、小目标等不确定状态人工复核。
5. 确认高处未挂立即报警，不等待数秒。遮挡前后已挂时，遮挡期间仅复核。
6. 每类违规 Precision、Recall 均至少95%；单路端到端至少30 FPS。测试条件、分辨率、硬件和事件延迟尚需实测定义。
7. 红框、类型、声音、截图、默认前10秒后20秒视频，可配置。
8. 人工复核：确认违规/确认正常/仍无法判断，保留审计历史。
9. 按时间、摄像头、人员/判定状态、复核结论检索，导出Excel。
10. 摄像头名称与安装位置进入事件和留证元数据。
11. 管理员管理账号、摄像头、配置、导出；值班员查看、接警、复核。
12. 每个版本在GitHub留档，保留源码、说明、模型/数据版本对应关系。

待定：可靠锚点现场标准；GB28181/RTSP/SDK接入方式；GPU和实际部署配置。
首版仅完成基础工作流和评估工具，自动识别与跟踪均待实现/验证。

后续优先次序：
- 修正并人工抽检数据，建立跨视频/场景独立测试集。
- 增补人员、工作服、高处、挂钩连接与挂点高度证据标注。
- 训练部件/关系模型并评估；证据未知保持人工复核。
- 接入多人跟踪、事件去重和非阻塞推理，再测端到端速度和告警延迟。
- 完善密码管理、配置持久化、摄像头重连、磁盘配额与证据保留周期。
